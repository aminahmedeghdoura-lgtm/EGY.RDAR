# رادار الجنيه - نسخة التحديث التلقائي

نسخة قابلة للاستضافة الذاتية من لوحة "رادار الجنيه"، بحيث تُحدَّث أسعار الدولار
واليورو مقابل الجنيه المصري **تلقائياً** من نشرتي بنك مصر والبنك العربي الدولي
عبر مهمة مجدولة (GitHub Action) بدل الإدخال اليدوي فقط.

## لماذا هذا مشروع منفصل عن نسخة المحادثة؟

الصفحة التي نشرتها لك داخل Claude مستضافة على claude.ai، وسياسات الأمان هناك
تمنع أي صفحة من الاتصال بأي عنوان خارجي تلقائياً (لا تحايل ممكن على هذا من
داخل تلك البيئة). الحل العملي الوحيد لتحديث تلقائي حقيقي هو استضافة الصفحة في
مكان تتحكم فيه أنت، مع مهمة صغيرة تعمل من طرف الخادم (لا من المتصفح) تقرأ
البيانات وتحفظها كملف تقرأه الصفحة. هذا ما يفعله هذا المشروع.

## ماذا يوجد هنا

```
index.html                          لوحة التحكم (نفس التصميم، مع إضافة قراءة تلقائية للبيانات)
data/rates.json                     آخر أسعار محفوظة (تبدأ بقيم حقيقية بتاريخ 9 سبتمبر 2026)
scripts/scrape.mjs                  سكربت Node.js يجلب الأسعار ويحدّث rates.json
.github/workflows/update-rates.yml  مهمة GitHub تُشغّل السكربت كل ساعتين تلقائياً
```

## خطوات التفعيل (٥ دقائق تقريباً)

1. أنشئ مستودعاً (Repository) جديداً على GitHub (يمكن أن يكون عاماً Public
   حتى تعمل صفحات GitHub Pages مجاناً).
2. ارفع كل ملفات هذا المجلد إليه (اسحب المجلد في واجهة GitHub، أو عبر git:
   `git init && git add . && git commit -m "init" && git branch -M main && git remote add origin <رابط مستودعك> && git push -u origin main`).
3. من إعدادات المستودع Settings → Pages: اختر النشر من الفرع `main` والمجلد
   `/ (root)`. بعد دقيقة أو اثنتين سيظهر رابط مثل
   `https://<اسم_حسابك>.github.io/<اسم_المستودع>/` — هذا رابط لوحتك المباشر.
4. من تبويب Actions: تأكد أن مهمة "تحديث أسعار الصرف" مفعّلة (GitHub يفعّلها
   تلقائياً عادة). يمكنك تشغيلها فوراً يدوياً أول مرة من زر Run workflow
   بدل انتظار الجدولة، للتأكد أنها تعمل.
5. افتح رابط GitHub Pages: يجب أن ترى في أعلى اللوحة رسالة خضراء بجانب
   "آخر مزامنة" تفيد أن الأسعار محدّثة تلقائياً.

## التحقق والصيانة (مهم)

لم يُتح لي عند كتابة السكربت فحص كود الصفحتين المصدر مباشرة (الأداة التي بنيت
بها هذا المشروع تتصفح الويب عبر ملخّص وليس عبر HTML خام)، لذلك بُني الاستخراج
على نمط عام (البحث عن اسم العملة ثم أقرب رقمين) بدل محددات دقيقة لجدول
الصفحة. راقب أول 2-3 تشغيلات من تبويب Actions:

- إذا ظهر التشغيل باللون الأخضر ونجح السكربت، افتح `data/rates.json` بعدها
  وقارن الأرقام يدوياً مع نشرة بنك مصر لمرة واحدة للتأكد.
- إذا فشل أو أعطى تحذيرات (raise فى الـ log)، افتح تفاصيل التشغيل لقراءة رسالة
  الخطأ - غالباً يعني أن هيكل صفحة المصدر تغيّر، وستحتاج لتعديل دالة
  `extractRate` أو التسميات (`labels`) في `scripts/scrape.mjs`. أرسل لي وقتها
  رابط تشغيل الـ Action الفاشل أو نص الخطأ وسأساعدك على تصحيحه.
- عند فشل الجلب، يحتفظ الملف بآخر قيمة صحيحة معروفة تلقائياً (لا يُكتب فراغ
  أو رقم خاطئ فوق البيانات الجيدة).

مصدر البنك العربي الدولي في هذه النسخة هو مجمّع خارجي (`ta3weem.com`) وليس
موقع AIB الرسمي، لأن موقع البنك يعرض الأسعار عبر جافاسكربت لا يظهر في HTML
الخام القابل للقراءة من طرف الخادم. هذا موضّح صراحة في واجهة اللوحة نفسها.

قبل تفعيل الجلب الدوري على نطاق واسع أو دائم، يُفضّل مراجعة شروط استخدام كل
موقع (Terms of Use) للتأكد من توافق ذلك معها. وتيرة كل ساعتين المضبوطة هنا
معقولة ولا تُحمّل الموقع المصدر ضغطاً.

## تعديل وتيرة التحديث

عدّل السطر `cron: '15 */2 * * *'` في
`.github/workflows/update-rates.yml` (بتوقيت UTC). مثلاً `0 * * * *` لتحديث كل
ساعة، أو `0 6-18 * * 0-4` لتحديث كل ساعة من 6 صباحاً حتى 6 مساءً بتوقيت UTC
أيام الأحد-الخميس (أيام عمل البنوك المصرية تقريباً، مع فارق التوقيت).

## الإدخال اليدوي ما زال متاحاً

زر "تحديث الأسعار يدوياً" في اللوحة ما زال يعمل، ويُستخدم كخط دفاع احتياطي إذا
تعطّل الجلب التلقائي مؤقتاً، أو إن أردت تجربة سيناريو سعر افتراضي.
